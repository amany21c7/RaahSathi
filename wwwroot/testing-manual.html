RaahSathi Operational Guide

Point-to-point guide for testing every tool, option, and workflow across Customer, Mechanic & Admin portals.

Core Technology Stack: ASP.NET Core MVC (.NET 9.0) • Entity Framework Core (SQL Server) • Leaflet JS Maps • Haversine Distance Engine • Zero-Flash 10-Language Switcher • Emergency SOS Engine

1. Public Home Page & Global Header Options

  • Brand Logo: Header top-left logo par click karke aap hamesha Home page (`/`) par navigate kar sakte hain.
  • Navigation Pills:
    • Home: Main Hero Banner, Emergency Request CTA, Live System Status card.
    • Services: 2-Wheeler, Car, Commercial, aur Heavy Vehicle categories ke rates aur info.
    • How It Works: 3-Step automated workflow (Request ➔ Auto Dispatch ➔ Repair).
    • About Us: Network stats, KYC safety protocols, aur escrow rules.
    • Contact Us: Support helpline (`1800-102-7224`), office location, and contact form.
  • Zero-Flash Multi-Language Engine: Header dropdown se 10 Indian Languages (*English, Hindi, Marathi, Gujarati, Punjabi, Bengali, Tamil, Telugu, Kannada, Malayalam*) bina page reload kiye instant translate hoti hain.
  • Footer & Tricolor Badge: Copyright text ke sath Make In India tri-color badge.

2. Emergency SOS & AI Chatbot Options

  • Red SOS Button Trigger: Top Navbar SOS, Footer SOS, ya Dashboard SOS button dabane par instant 24x7 Support Modal khulta hai jisme 3 options milte hain:
    1. Toll-Free Helpline: Direct 1800-102-7224 call link.
    2. Instant Dispatch: 30-Second Express Breakdown Request.
    3. WhatsApp Control Desk: WhatsApp support desk.
  • Floating AI Chatbot Widget: Screen ke bottom-right corner me Chat button par click karne par popup AI Assistant khulta hai jo booking aur charges ki instant help karta hai.

3. Customer Operations Portal (`/Customer/...`)

  • Dashboard (`/Customer/Dashboard`): Saved vehicles list, 1-click Quick Request button, Active ongoing breakdown dispatch cards, and Past service history.
  • Instant Request (`/Customer/Book`): Browser GPS Geolocation location auto-detect karta hai. Unauthenticated guest users ke liye verification code (`1234`) se 10-second instant account creation.
  • Live Dispatch Tracker (`/Customer/Tracker`): Customer live ETA countdown, mechanic location map radar, status timeline (*Requested ➔ Accepted ➔ In Progress ➔ Completed*), aur mechanic contact phone/photo dekh sakta hai.

4. Mechanic Field Operations Portal (`/Mechanic/...`)

  • Duty Toggle: Mechanic Online / Offline status switch kar sakta hai. System sirf Online mechanics ko hi nearby job broadcast bhejta hai.
  • Incoming Broadcast: Nearby breakdown hone par customer distance (km), visiting fee, aur problem type ka live popup alert milta hai.
  • Job Execution: Mechanic *Accept Job* ➔ *Start Journey* ➔ *Submit Custom Parts Estimate* (if required) ➔ *Complete Work* mark kar sakta hai.

5. Admin Command & Operations Console (`/Admin/...`)

  • Global Live Dispatch Radar: Entire city/highway ke active breakdown requests aur mechanics ko real-time Leaflet map par plot karta hai.
  • KYC Verification Module: Mechanics ke Aadhaar, Driving License, aur Workshop photos review karke `Approve` ya `Reject` karne ka control.
  • Dynamic Pricing Rules (`/Admin/PricingRules`): Vehicle-wise Base Visiting Fee aur Per-Km Rate manage karne ka portal.
