RaahSathi End-to-End Operational Manual

Detailed function-by-function execution guide, testing procedures, expected outcomes, and fail-safe checks for all portals.

1. Customer Assistance Booking & Live GPS Dispatch Flow (`/Customer/Book`)

Yeh module stranded vehicle owners (Customers) ko 10 second me breakdown mechanic request submit karne deta hai.

A. Browser GPS Geolocation Auto-Detection
  • Kaise Work Karta Hai: User jab `/Customer/Book` page kholta hai, toh browser ka Native HTML5 Geolocation API (`navigator.geolocation.getCurrentPosition`) automatic Latitude aur Longitude capture karta hai aur OpenStreetMap Nominatim reverse-geocoding se exact street address fill karta hai.
  • Testing Step: Page load hone par Browser location permission "Allow" karein. Input box me aapka live area address automatic populate ho jayega.
  • Expected Outcome: Latitude/Longitude map pins accurate set honge aur Form input field me location text show hoga.
B. 2-Layer Upfront Price Estimation
  • Kaise Work Karta Hai: Upfront Estimate 2 layers se milkar banta hai:
    • Layer 1 (Visiting Fee): Category Base Fee + (Haversine GPS Distance in KM * Per-KM Rate).
    • Layer 2 (Service Fix Fee Range): Database `ProblemTypePricings` table se live Min/Max range (e.g., Flat Tyre ₹200-800).
  • Testing Step: Vehicle Category ("Car") aur Problem ("Flat Tyre / Puncture") select karein. Live price estimate breakdown change hoga.
  • Expected Outcome: Final Estimated Bill auto-calculate hoga aur user ko upfront estimate show karega.
C. Guest User Auto-Registration (Verification Code `1234`)
  • Kaise Work Karta Hai: Agar user logged-in nahi hai, toh Phone Number aur Name daalte hi system background me Auto-Account create karta hai aur instant authentication cookies set kar deta hai. Verification code strictly `1234` hai.
  • Testing Step: Unauthenticated window me Phone `9876543210` daalkar "Request Patrol Mechanic Now" click karein.
  • Expected Outcome: Account create hokar request DB me `Status = 'Requested'` save hogi aur user automatically `/Customer/Tracker` page par redirect ho jayega.
Key Endpoints Tested: `POST /Customer/Book`, `GET /Customer/Tracker`, `GET /Customer/GetJobInvoiceDetails`

2. Mechanic Field Operations Portal (`/Mechanic/...`)

Patrol mechanics ke mobile dashboard me jobs accept karne, emergency alerts receive karne, aur payment QR generate karne ki poori functionality.

A. Duty Status Toggle (Online / Offline)
  • Kaise Work Karta Hai: Mechanic dashboard par `Online / Offline` switch hota hai. Tabhi `MechanicProfiles.IsOnline = true` update hota hai. Dispatch Engine strictly sirf Online mechanics ko hi nearest job assign karta hai.
  • Testing Step: `/Mechanic/Dashboard` me toggle switch click karein.
  • Expected Outcome: Switch color Green (Online) ho jayega aur badge "PATROL ACTIVE" display karega.
B. Broadcast Emergency Alert & Job Lifecycle Execution
  • Kaise Work Karta Hai: Nearby request aate hi mechanic ke mobile screen par distance, customer location, aur visiting fee ka alert pop-up hota hai. Mechanic lifecycle status change karta hai:
    Requested → Accepted → En Route → In Progress → Completed
  • Testing Step:
    1. Customer side se Job Request submit karein.
    2. Mechanic dashboard refresh karein aur "Accept Job" button dabayein.
    3. "Start Journey" → "Arrived at Location" → "Submit Parts Estimate" (if needed) → "Complete Job" steps execute karein.
  • Expected Outcome: Job status database aur customer Live Tracker page par in real-time update ho jata hai.
C. QR Code Payment Generation & Wallet Escrow Credit (`/Mechanic/ProcessQrPayment`)
  • Kaise Work Karta Hai: Job completion par Mechanic customer ko QR code show karke payment collect karta hai. Backend me `IPaymentService.ProcessEscrowPaymentForJobAsync` trigger hota hai:
    • Tiered Commission Calculate hota hai (8% for < ₹1000, 10% for ≥ ₹1000).
    • Net earnings Mechanic Wallet Balance (`CurrentEarnings`) me automatically credit hoti hain.
  • Testing Step: Mechanic Dashboard me "Generate Payment QR" par click karein aur confirm payment karein.
  • Expected Outcome: Wallet Balance instant update ho jata hai aur Commission deduct hone ke baad breakdown message alert milta hai.
Key Endpoints Tested: `POST /Mechanic/ToggleDuty`, `POST /Mechanic/AcceptJob`, `POST /Mechanic/ProcessQrPayment`

3. 100% Fail-Safe Escrow Payment Architecture (`Controllers/PaymentController.cs`)

Platform ka payment engine Layered Architecture (Controller → Service → Repository) follow karta hai with 100% zero-crash guarantee.

A. Double-Layer Transaction Fallback Mechanism
  • Kaise Work Karta Hai: When payment processing is invoked (`ProcessEscrowPaymentForJobAsync`):
    1. Layer 1 (Stored Procedure): System executes SQL Server Stored Procedure `dbo.rs_payments_process_escrow`.
    2. Layer 2 (C# EF Core Transaction Fallback): Agar SQL Procedure missing ho ya DB error aaye, catch block auto-trigger hokar C# EF Core direct database transaction se Payment status, Escrow lock, Admin Commission, aur Mechanic earnings complete karta hai.
  • Testing Step: `/Payment/ProcessEscrowPayment?jobId=1` execute karein.
  • Expected Outcome: Payment record `PaymentStatus = 'Released'` save hoga aur overall system me koi crash ya null-pointer error nahi aayega.
Key Classes: `IPaymentRepository`, `PaymentRepository`, `IPaymentService`, `PaymentService`, `PaymentController`

4. City-Wise & Problem-Wise Dynamic Pricing Engine (`/Admin/Pricing`)

Admin console se breakdown problem rates aur base distance fees ko city-wise update karne ka central control.

A. Edit / Update Problem Rate Modal (`#editProblemModal`)
  • Kaise Work Karta Hai: Admin Pricing table me har row ke aage "Edit" button hota hai. Edit button dabane par modal me existing values pre-fill hoti hain. Submit karne par `IPricingService.UpdateProblemPriceRateAsync` call hota hai.
  • Testing Step: Admin console (`/Admin/Pricing`) me "Flat Tyre / Puncture Repair" ke aage Edit click karein. Min Service Charge ko `200` se badlkar `250` karke Save Changes karein.
  • Expected Outcome: Table me instant naya rate ₹250 reflect ho jata hai.
B. Real-Time Global Price Propagation (Har Jagah Instant Reflect)
  • Kaise Work Karta Hai: Admin se rate update hote hi backend Database `ProblemTypePricings` update hone ki wajah se poore platform par auto-reflect hota hai:
    • Front Page Estimator (`/`): Dynamic calculation me naya ₹250 rate use hota hai.
    • Services Page (`/Home/Services`):** Price badge auto-update hota hai.
    • Customer Booking (`/Customer/Book`): Customer estimate bill new rates se generate hota hai.
    • AI Chatbot (`/Home/AskAiChat`): AI System Prompt live DB query se naya ₹250 rate parse karke chat me naya rate hi user ko bataata hai.
  • Testing Step: Admin se rate edit karne ke baad Front Page Calculator test karein aur AI Chatbot se poochein "What is Tyre repair price?".
  • Expected Outcome: Chatbot aur Estimator dono me exact naya rate ₹250 hi dikhai dega.
Key Endpoints Tested: `POST /Admin/UpdateProblemTypePrice`, `POST /Admin/AddProblemType`, `POST /Admin/UpdatePricingRule`
